Keep apps from GitHub releases up to date

A small tray app for Ubuntu and Windows. It notices new releases of the apps you installed from GitHub, then downloads, verifies and installs the .deb or .msi when you click Install.

Download View on GitHub

Why

Many great desktop apps ship only as a .deb or .msi on their GitHub releases page. No apt repository, no Microsoft Store, no auto-updater. You install them once and quietly fall behind. GitHub Release Updater watches those repositories and brings you the new version, like Obtainium does on Android.

Features

Watches any public repo

Paste owner/name or a release URL. Checks every 6 hours (configurable) or on demand.

Picks the right file

Matches your OS and CPU (x64, arm64, x86) and skips CLI, portable and other-architecture assets. Override with a regex per app.

Straight to latest

Jumps directly to the newest release and re-checks right before installing.

Verified downloads

SHA-256 from GitHub's asset digest, .sha256 files or SHA256SUMS. HTTPS only, GitHub hosts only.

You stay in control

Nothing installs in the background. You click Install, then approve the polkit (Ubuntu) or UAC (Windows) prompt.

Native installers

apt-get install ./app.deb resolves dependencies; msiexec shows MSI progress. Uninstall from the same window.

Backup & restore

Export settings to JSON or back up automatically to Backblaze B2. Secrets never go into backups.

Tiny and quiet

Built with Rust and Tauri. Starts at login in the tray and stays out of your way.

Free and open source

MIT licensed. No telemetry, no account needed.

Install

Ubuntu 22.04+ / Debian

  1. Download gh-release-updater_<version>_amd64.deb from the latest release.
  2. Install it:
sudo apt install ./gh-release-updater_*_amd64.deb

Windows 10 / 11

  1. Download gh-release-updater_<version>_x64.msi from the latest release.
  2. Double-click it. The installer is not code-signed yet, so SmartScreen asks once: More info → Run anyway.

Then add a repository on the Applications page. The app can track its own repository to update itself.

FAQ

How do I automatically update a .deb installed from GitHub?

Add the repository on the Applications page. The app checks for new releases, picks the .deb for your CPU, verifies its checksum and installs it with apt after you approve.

Does it install updates without asking?

No. Every install needs your click and the OS elevation prompt (polkit on Ubuntu, UAC on Windows).

Do I need a GitHub token?

No. Without one GitHub allows 60 API requests per hour, enough for dozens of apps. An optional fine-grained token with no permissions raises that to 5,000. It is stored only on your machine.

What if the app picks the wrong asset?

Set a per-app regex pattern for Linux and Windows on the Applications page, or report it so the default rules improve.

Fedora, Arch, macOS, AppImage?

Not yet. Ubuntu/Debian (.deb) and Windows (.msi) are supported today. Upvote or open an issue for the platform you need.

Is it safe?

It installs what the repository owner publishes, so only track projects you trust. Downloads are HTTPS-only from GitHub hosts and checksum-verified when a checksum is published. See the security policy.
