# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, critique code and ideas rather than people,
and keep discussions on topic. Harassment of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainer through
[GitHub Security Advisories](https://github.com/phil288/github-release-updater/security/advisories/new)
or by contacting [@phil288](https://github.com/phil288). Reports are handled confidentially.
